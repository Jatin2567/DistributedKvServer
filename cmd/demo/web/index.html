A note on this experiment.

Three real Raft nodes share one host. Data lives in memory and resets when the service restarts or sleeps. This public playground is shared by everyone; use sample data only. Reads reflect the leader’s local state and may be stale during a network partition. Up to 10,000 log entries per run.
